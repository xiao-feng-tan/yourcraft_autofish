只适配1.21,1  fabric  <br>
该模组只适用于yourcraft服务器!对于原版和其他服务器钓鱼机制无效!  
### 默认键位[F8]
## 模组具体机制流程如下
- 检测到服务器发送空标题包 -> 右键 -> 持续检测服务器发包 -> 检测到发送最后一个包,两秒过后,若聊天框没有显示"您获得"则右键10下(反之结束该轮) ->最后检测是否有浮漂,有就结束,没有则右键  
- # 收杆延迟和随机波动用于调节检测到包后多久右键,补偿延迟用于调节发包结束后多久截至检测聊天框并且点10下
- 请下载最新版本的jar文件确保无bug.
